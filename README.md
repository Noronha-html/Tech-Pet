# Tech-Pet
### 🐶 O que é o nosso projeto?
Nosso projeto consiste em um chaveiro com um QR code envolto em uma resina para uma maior resistência, ao ser escaneado redireciona para um site com informações do pet e o número de contato do dono, viabilizando que seu pet perdido possa ser encontrado, e a pessoa que encontrar o pet possa entrar em contato com o dono e devolve-lo.
